# 기술 설명

## 디스크 구성

| 파일 | 내용 |
| --- | --- |
| `CAP5.EXE`~`CAPA.EXE`, `CAPH.EXE` | 챕터별 실행파일(다섯~열 번째 소문, 종장). 모두 약 0x80035000에 올라감 |
| `DAT/CAPn/*LINK.CDB` | 챕터 데이터. 대본·배경·그림이 들어 있는 CDB 컨테이너 |
| `DAT/FONT/KFONT.CDB` | 챕터별 대사 글꼴(엔트리 CAP5:2, CAP6:3, CAP7:0, CAP8:5, CAP9:6, CAPA:4, CAPH:7) |
| `DAT/ALLCAP/CTLINK.CDB` | 챕터 시작 타이틀 카드(엔트리 0~5) |
| `DAT/SINKOU/MENUDAT.BIN`, `PROGDAT.BIN`, `MEMDAT.BIN`, `ALLLINK.CDB` | 진행 화면(타이틀 「시작/준비」, 진행 메뉴, 메모리 카드 안내) |

CDB는 2048바이트 헤더에 `[시작 섹터 u16, 섹터 수 u16]` 엔트리 표가 있고 데이터는 섹터 단위로 정렬됩니다(`tools/cdb.py`). 재패킹하면 크기가 바뀔 수 있어, 디스크의 파일 영역을 교체하거나 빈 곳으로 옮기고 ISO9660 디렉터리를 고칩니다(`tools/disc.py`, `tools/iso.py`, 섹터 EDC/ECC 재계산 `tools/cdsec.py`).

## 압축

엔트리 안 데이터는 여러 개의 압축 덩어리가 이어 붙은 형태입니다. 명령 바이트 `00~7F` 리터럴, `80~BF` 런, `C0~DF` 역참조, `E0~EF` 등차 수열, `FF` 끝입니다(`tools/lz.py`, 해시 체인 압축기). 그림 덩어리는 게임이 오프셋으로 찾아가므로 `comp_fit`으로 다시 압축한 결과를 원래 길이와 정확히 같게 맞춥니다. 같은 그림 덩어리가 여러 파일에 사본으로 들어 있어(예: `ALLLINK.CDB`의 타이틀 메뉴), 빌드는 디스크의 모든 데이터 파일에서 원본 압축 바이트열을 찾아 새 것으로 바꿉니다.

## 대본

- 대본은 u16 토큰 스트림을 압축한 블록의 나열이며 0x801F0000(한도 0xE000)에 올라갑니다(`tools/script.py`, `tools/tok.py`).
- 실행파일 안의 블록 포인터 표는 대본 블록 목록을 이어 붙인 형태입니다(CAPA는 엔트리 9 다음 8). `build.py`의 `script_ptrs`가 원본 블록 오프셋 순서로 표를 찾아 새 위치로 고칩니다.
- 포인터가 없는 대본 `CAP7 YHLINK 1`은 블록을 원본과 같은 오프셋에 다시 써 넣고, 자리가 모자란 블록은 원문을 유지합니다. `K6LINK 5`는 쓰이지 않는 데이터라 번역하지 않았습니다.
- 번역은 블록 번호별 `{"id","ko"}` JSON이며, 제어 태그는 `{8408}` 형태로 원문과 같은 순서·개수를 유지합니다(`tools/chk.py`가 태그·줄 수·한 줄 폭을 검사).

## 글꼴

- 원래 대사 글꼴은 실행파일의 고정 글리프 표를 참조합니다. 한글 글꼴은 `KFONT.CDB`의 챕터별 엔트리를 교체해 0x8001A200에 올립니다.
- 엔트리 구조: `+0` 원본 CLUT(0x91바이트, 그대로 유지), `+0x98` 2bpp→4bpp 확장 루틴(MIPS), `+0x120` 글리프 표 `{포인터, 폭}`×N, 그 뒤 16×16 2bpp 글리프(64바이트씩). 실행파일마다 표 참조 4곳(lui/addiu 쌍)과 글리프 해제 호출(`jal`)을 새 주소로 고칩니다.
- 코드 0x00~0xDB는 모든 챕터 공통 글리프(숫자·기호 등), 0xDC부터 그 챕터 대본에 쓰인 한글을 빈도순으로 배정합니다. 글꼴 뒤에 다른 버퍼가 있어 챕터별 상한(`FONT_MAX`)이 있으며, 종장(CAPH)은 공간이 좁아 쓰지 않는 가나 공통 글리프를 덜어 냅니다.

## 그림 글자

TIM(4bpp/8bpp) 그림의 인덱스를 직접 다시 그립니다(`tools/gfxpatch.py`). 팔레트는 바꾸지 않습니다. 챕터 타이틀 카드는 160×240 8bpp 두 장씩 18프레임의 페이드 애니메이션이라, 프레임마다 원래 압축 길이에 들어가도록 배경을 행 단위로 단순화하며 글자를 그립니다.
