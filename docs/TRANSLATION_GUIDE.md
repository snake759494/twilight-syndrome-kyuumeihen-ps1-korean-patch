# 트와일라잇 신드롬 ~구명편~ 번역 지침

모든 명령은 저장소 폴더에서 실행합니다.

## 파일
- 원문: `text/ja/<이름>.json` = `[{"id": n, "ja": "..."}]` (게임 글꼴을 OCR로 읽은 것이라 한자 오인식이 섞여 있음)
- 번역: `text/ko/<이름>.json` = `[{"id": n, "ko": "..."}]` — 원문의 **모든 id**를 같은 순서로 넣는다. UTF-8, `ensure_ascii=False`.
- 검사: `python tools/chk.py <이름>` → 마지막 줄이 `문제 블록: 0 / N`이 될 때까지 고친다.

## 반드시 지킬 형식
1. `{8600}`, `{8d03}`, `{d600:0007}` 같은 `{...}` 태그는 **원문과 똑같은 순서·개수**로 둔다. 태그 위치는 문장 의미에 맞게 자연스러운 곳에 두되 순서는 바꾸지 않는다. 태그만 있는 블록은 그대로 복사.
2. 줄바꿈 `\n` 개수는 원문과 **같게**. (`{8408}` 등 `84xx`는 표시 대기 태그이며 줄바꿈이 아님)
3. 한 줄의 표시 폭 제한(검사 도구가 px로 계산). 넘치면 더 짧게 의역한다. 한글 한 글자 ≈ 15px.
4. 화자 표시 `ミカ:대사` → `미카:대사` 형식 유지(콜론 앞 이름, 공백 없음). 선택지 `{8200}:가야 해` 형식도 유지.
5. 행 머리의 전각 공백 `　`(내레이션 들여쓰기)은 원문과 같은 위치에 그대로 둔다.
6. 말줄임표는 원문처럼 `・・・`를 쓴다. `？` `！`는 반각 `?` `!`로. 그 밖에 쓸 수 있는 문자: 한글, 숫자, 영문, `.,?!~-()「」『』・`. 일본어 문자(가나·한자)는 남기면 안 된다.

## 번역 원칙
- **기계 번역 금지.** 문맥을 보고 직접, 자연스러운 한국어 구어체로 번역한다. 여고생 셋의 말투(유카리: 시원시원하고 털털한 반말, 치사토: 차분하고 상냥한 말투, 미카: 발랄하고 선배들에게 존댓말 섞인 말투 `~요`)를 살린다.
- OCR 오인식 한자는 문맥으로 바로잡아 이해한다. 흔한 예: 車→事, 雪→書, 柿→怖, 枇→世, 略→暗, 冊→聞, 迫→連, 戸→声, 厘→屋, 謙→議, 誼→語, 妥→安, 簡→闇, 逸烏→逸島, 単井→岸井, 嵩際→窓際, 昔→音, 胃話→電話, 逹→達, 艮/▲/丑→A/B 등.
- 인명은 일본어 발음(국립국어원 표기): 하세가와 유카리, 이쓰시마 치사토, 기시이 미카, 료(リョウ), 사에키, 구로다, 다타라, 가와이, 기타무라, 이나가키, 마유미, 미호, 기미카. 학교: 도립 히나시로 고교.
- 화자명: 老人 노인, 母親 어머니, 兵士 병사, 神父 신부, 老婆 노파, 占い師 점쟁이, 巡査 순경, 芝居屋 연극꾼, 女子A 여학생A, 女性 여자, 労務者 인부, 男子生徒 남학생, 工員 직공, 紳士 신사, 先生 선생님, 逸島母 치사토 엄마, レジ 점원, 小僧 꼬마, 主婦 주부. (오인식된 이름은 문맥으로 판단)
- センパイ → 선배, ウワサ(噂) → 소문, ～ちゃん은 이름만 부르거나 친근한 호칭으로 자연스럽게.
- 번역 결과를 만들 때는 파이썬 스크립트로 JSON을 쓰되, 번역문 자체는 직접 작성한다(외부 번역기/API 사용 금지).
- 작업 폴더 밖에는 아무것도 저장하지 말 것. 임시 파일은 끝나면 삭제.
